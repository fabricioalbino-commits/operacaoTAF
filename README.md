# Operação TAF

Protótipo inicial de uma página de inscrição para uma consultoria de preparação para o Teste de Aptidão Física (TAF).

## Como abrir

Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript sem dependências ou etapa de build.

## Estado atual

A página apresenta a consultoria e coleta os campos do formulário no navegador, mas ainda não envia nem armazena os dados. Antes de usar inscrições reais, conecte o formulário a um backend e defina como os dados serão protegidos.
