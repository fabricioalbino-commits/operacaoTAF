# Operação TAF

Projeto informativo para localizar concursos públicos que podem exigir Teste de Aptidão Física (TAF) e acessar os canais oficiais dos órgãos.

## Como abrir

Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript sem dependências ou etapa de build.

## Funcionalidades

- Lista concursos de Goiás, nacionais e municipais.
- Filtra os concursos por estado ou abrangência.
- Aponta para os sites oficiais dos órgãos.

As informações sobre TAF, editais e inscrições devem ser confirmadas nos canais oficiais. O projeto é estático e não consulta nem atualiza concursos automaticamente.
